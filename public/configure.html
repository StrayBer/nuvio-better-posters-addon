Install in Nuvio

  1. Generate the manifest URL above, then press Install to Nuvio or copy the link.
  2. If you copied it: in Nuvio open Settings → Addons and add that URL.
  3. Disable the original catalog addon you wrapped, so its rows do not show twice.

Titles that BetterPosters has no artwork for keep their normal poster. The link contains the addon URLs in readable form, so do not wrap addon URLs you consider secret.
